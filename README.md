# 你好，我是凝恩

独立开发者，自研**全中文编程语言「凝恩」（NINGEN）**。

让中文成为编程的一等公民。

## 正在做

- **凝恩语言**：全中文自然语言级编程语言
  - 全自研编译器（ngas 中文汇编器 / m0 汇编器）
  - 字节码 VM / JIT
  - NGX2 保护容器、ngkey 签名工具
  - ARM64 全自研工具链
- **凝恩3D**：自研 3D 雕刻 / 建模 App
- **凝恩语言 App**（正式版）
